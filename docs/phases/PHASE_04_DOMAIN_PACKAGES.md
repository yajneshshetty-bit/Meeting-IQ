# Phase 4 — MeetingIQ Domain Packages

**Prerequisite:** Phase 3 complete.

## Authority

Read and follow: [`../MEETINGIQ_PHASE1_IMPLEMENTATION.md`](../MEETINGIQ_PHASE1_IMPLEMENTATION.md) § Phase 4

## Tasks

1. Create MeetingIQ domain package (entitlements, corpora, policy scope)
2. Define data profiles: meetings, opportunities, accounts, activities, forecasts
3. Define search profiles: Command Center queries, Executive View queries
4. Create policy bundles mapping roles → entitlements
5. Create AI templates (structure only — LLM wiring in Phase 7)
6. Register and activate all packages on Zambyl stable channel
7. Update [`../PLATFORM_USAGE_REPORT.md`](../PLATFORM_USAGE_REPORT.md)

## Exit Criteria

- [ ] Domain package activated
- [ ] Profiles and policies registered
- [ ] Role → entitlement mapping documented
- [ ] Search profiles return ingested data

## Do Not

- Build UI
- Modify kernel
